FIXES APPLIED
-------------
1. HIGH / panic: commands.rs thread::scope JoinHandle.join().unwrap() (4x).
   Crate uses panic="abort" (lib.rs:264), so a panicking probe thread would
   abort the whole app. Changed to .unwrap_or_else(|_| { eprintln!(...); <default> })
   so a panicked probe thread degrades gracefully instead of aborting.
2. MEDIUM / swallowed thread joins: commands.rs (stdout/stderr reader threads)
   and hook_client.rs (stdin reader thread) discarded join() results. Added
   .map_err(|e| eprintln!(...)) so thread panics are surfaced instead of lost.
3. LOW / panic: hook_client.rs "127.0.0.1".parse::<IpAddr>().unwrap() replaced
   with std::net::Ipv4Addr::LOCALHOST (idiomatic, no unwrap).

REVIEWED, NO CHANGE NEEDED

- Unhandled JS promise rejections (pet.js): all .then() chains already have
